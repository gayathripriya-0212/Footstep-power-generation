# Footstep-power-generation
Arduino Uno based footstep power generation using piezoelectric sensors

## About
This project demonstrates generation of electrical energy from human footsteps using piezoelectric sensors and Arduino Uno.

## Project Prototype

![Project](Screenshot_2026-05-27-14-27-33-343_com.whatsapp.jpg) 

## Components Used
- Arduino Uno
- Piezoelectric Sensors
- Breadboard
- LED Modules
- Battery Holder
- Diodes
- Resistors
- Connecting Wires

## Objective
Generate electrical energy from footsteps using piezoelectric sensors.

## Result
Prototype successfully demonstrated energy generation and output indication.
